# LLM Usage Report — Week 2 (ПДн Контроль)

This report discloses how AI/LLM tools were used during Assignment 2. All AI outputs were
reviewed and edited by team members; the substantive decisions (scope, priorities,
customer approvals) are original team work.

> Note on terminology: the **product itself** uses an LLM (Qwen) to analyze policy/consent
> texts — that is a product feature, documented in `CLAUDE.md`, not assignment tooling.
> This report covers AI tools used to *produce the Assignment 2 deliverables*.

## Tools used

The only AI/LLM tool used for Assignment 2 was **Claude Code (Claude Opus, Anthropic)**.

The Figma prototype and the customer-meeting transcript were produced **manually, without
AI**.

## How AI was used per activity

- **Writing / documentation — Claude Code.** Drafting and restructuring the Week 2 report
  files: the `reports/week2/README.md` index, `analysis.md`, the `mvp-v0-report.md`
  skeleton, and this `llm-report.md`. Also used to translate `customer-meeting-summary.md`
  from Russian to English while preserving structure and tables, and to review the Week 2
  reports against the Assignment 2 specification (producing a gap/TODO list). Small
  mechanical edits as well: moving the MIT-consent screenshot into `images/`, fixing an
  Obsidian image embed, updating the US-07 priority, and adding root-README links.
- **Code — Claude Code.** Used to assist with MVP v0 implementation and bug fixes during
  the week. All generated code was reviewed and tested by the team before being merged.
- **Prototyping — no AI.** The Figma prototype was designed manually by the team.
- **Transcription — no AI.** The customer-meeting transcript was written and sanitized
  manually from the recording (real names replaced with usernames/pseudonyms, PII
  redacted).
- **Research / idea generation — no dedicated AI tool.** Done by the team.

## Verification and responsibility

- All AI-generated text and code were read, edited, and tested by the team before
  submission; remaining placeholders/TODOs mark anything not yet verified.
- No real credentials, PII, or confidential business information were given to AI tools;
  customer names appear only as redacted placeholders / GitHub usernames.
- The analysis, prioritization, and customer approvals reflect the team's own work and the
  customer's actual decisions, not AI-generated filler.
